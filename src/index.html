Welcome to Remote Dev Bridge

This app lets Claude access your remote development servers over SSH. To get started:

  1. Add a server below (host, username, SSH key path).
  2. Create a project pointing to a directory on that server.
  3. Go to Settings → Copy Claude Desktop Config and paste it into your claude_desktop_config.json.
  4. Restart Claude Desktop and ask Claude to list your projects.
